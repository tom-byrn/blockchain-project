# Statement on Use of Generative AI

Generative AI was used to help plan and structure this project, including suggestions for the static frontend architecture, Solidity contract structure, documentation templates, and testing checklist. The generated content was reviewed and adapted for the assignment requirements. The final submitted work should be checked, tested, and understood by the student before submission.

No private keys, wallet passwords, seed phrases, or real cryptocurrency credentials should be entered into generative AI tools.
